# ⚔️ HEIMDALL

> **High Efficiency Intelligent Modular Digital Assistant for Learning, Development and Operations**

HEIMDALL is a modular AI Operating System built in Python.

Its long-term vision is to become an intelligent personal AI capable of natural conversation, voice interaction, computer control, long-term memory, internet intelligence, developer assistance, and autonomous workflows.

# 🛠️ Installation

Clone the repository:

```bash
git clone <repository-url>
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Create a `.env` file:

```env
GROQ_API_KEY=your_api_key
TAVILY_API_KEY=your_api_key
MODEL_NAME=llama-3.1-8b-instant
```

Run HEIMDALL:

```bash
python heimdall.py
```
